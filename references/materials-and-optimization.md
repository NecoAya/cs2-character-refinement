# 材质修复与预算优化

## 从实际使用的输入定位

白模、暗部异常或“金属没了”并不唯一指向底图。检查源材质、导出映射、最终编译 shader/参数、RERL 纹理引用、解码像素、UV、网格分配和当前装载文件。Blender 或 ModelDoc 静态正常，不能证明游戏使用同一文件、同一动画姿态或同一材质通道。

耳朵/薄片消失时，依次区分整个网格不在、蒙皮/姿态移位、render group/LOD 选择、背面剔除、alpha 裁剪和依赖问题。不要在没有顶点/像素证据时，把所有消失都归为 AO 溢出或直接重绑头骨。

### AO 与 alpha 的计算和编译检查

分别检查数值表示与遮罩运算，不把两者当同一种问题：

- 常量的归一化值、整数通道值和编译器语法不能混用。例如 8 位通道中的整数 1 与归一化白色 1.0 不是同一个量；通过当前编译器回读像素核验 AO 的白值和通道语义，不假设所有路线都以同样方式解释常量。
- 遮罩乘法前使用足够宽的数值类型，计算后 clamp；int16 等有限整数的溢出不能靠事后扩类型恢复。编译后的 alpha 覆盖率、尺寸、裁剪阈值、mip 与格式均需回读。

需要 alpha 时确认它实际进入 shader 的有效输入和最终压缩纹理；源文件有独立遮罩不代表编译引用了它。不要固定强制某种压缩格式，选择本机编译器和 shader 支持且保持所需通道的方式。

改不透明双面可以诊断透明路线，但会填实镂空/蕾丝；作为正式方案必须记录用户接受的视觉取舍。换 shader、调 AO、提高填光和改 alpha 分开做，避免归因混乱。

### “脸部法线坏了”

先问/查是凹凸贴图、顶点法线、切线、面朝向、阴影、AO，还是受光风格。当前 shader 根本没用凹凸法线时，不重绘一张并称修复。平面法线贴图也不等于模型没有顶点法线。

优先在相同场景曝光下比较。若实际只调了面部自发光填光，应如实命名为受光候选；填光可能减轻暗部，也可能洗掉层次，不能用它掩盖错误 AO。没有游戏反馈就不追认法线/阴影已经修复。

用户暂时无法截图时，先完成可做的材质输入、像素和网格静态检查；只有仍依赖观感才能区分的部分保持待测试，不把截图作为全部排查的前提。

### 丢色、金属与装饰质感

Unity 材质可能有主底图之外的颜色层、遮罩、MatCap、粗糙度/金属度或特殊 shader 参数。只迁移底图可能丢失局部原色；先查源材质实际层与 UV 遮罩，定位目标面，保护其他区域。

需要恢复附加颜色层时，核对原纹理、tint 与遮罩叠加方式，并按目标 UV 范围验证。恢复一层颜色不等于完整迁移原 shader 的所有光照。新增材质面组还要计 draw call 和编译块重排。

“高级感”需要区分银饰/宝石/织物：按原材料语义保留金属度、粗糙度、法线细节和透明特征，不能只用相同金属材质加焊接状几何。沿用已接受造型，不因局部颜色请求重做手型、UV、权重和其他首饰。

### 流光不是本体旋转

材质 UV 流动、发光呼吸、几何自转是三种独立效果。若仅实现前两项，明确本体旋转未实现；后者需实际动画/骨骼/运行时驱动并验证局部轴、挂点与游戏动画兼容。不得把静态截图或生成概念图当真实动态效果证明。

## 贴图预算

先明确预算是运行贴图、整个 addon、ZIP 还是显存；明确 MB 的十进制或 MiB 的二进制口径。递归统计两个视角实际引用的编译纹理闭包，共享路径只计一次，基础游戏外部资源另列。

分辨率按视觉价值分配：先保护脸、眼睛、近景手部和关键轮廓纹理，再评估主体装饰；远小部件及低频 AO/粗糙度优先缩减。512/1024 是具体项目的预算选项，不是每个通道的最低或最高要求；常量纹理通常不必放大。

按完整通道语义去重。RGB 相同的平面法线也可能在 alpha 中打包不同粗糙度；只比较 RGB 无法证明可安全合并。法线贴图、颜色图与遮罩需各自正确的色彩空间、缩放与压缩处理，缩放法线后核验向量与解码结果。

每次调整重新编译并统计真实字节，不以 PNG/ZIP 体积估计游戏纹理大小。保留 alpha 边缘、蕾丝、细线及法线近景对照。达到贴图预算不意味着显存和多人 FPS 已验证；还要分别评估材质 draw call、透明叠加、几何与物理解算。

## 三角面预算

统一使用游戏实际三角形数，分别列第三人称、第一人称、默认显示组合和全部存储资源。DCC 多边形数与三角面数不混用。

减面保护脸、手、剪影、UV/材质边界、关节以及裙摆/发束中段的动态弯折区。形态键、可选网格存在时，不能只验证 neutral；不要为了静态导出清空需要保留的表情数据。

LOD 降低的是某距离的显示开销，却会新增存储网格。报告各级面数与总存储面数；导出预览可能只有 LOD0，应核验原生成品/完整源数据，不把未导出的 LOD 当不存在。游戏切换、观感和 FPS 仍单独验收。
